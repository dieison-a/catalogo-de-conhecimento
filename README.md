# Knowledge Hub

Catálogo local de conhecimento para demonstrar classificação, busca e descoberta de materiais em um contexto fictício de operações SaaS.

## Funcionalidades

- Pesquisa por título, assunto ou resumo.
- Filtros por categoria.
- Conteúdo de demonstração inteiramente local.

## Conteúdos relacionados

Modelagem do Conhecimento, Sistemas de Informação, Ética e Sociedade, Comunicação e documentação.

## Executar

Abra `index.html` em um navegador. O protótipo não envia perguntas ou dados a serviços de IA.
